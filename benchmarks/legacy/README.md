# Замеры до версионирования

Сюда складываются графики и цифры, которые невозможно надёжно привязать к коммиту,
модели и набору — в основном прогоны июня – сентября 2026, когда модель ФИО и
наборы менялись несколько раз за неделю.

Пока папка пуста намеренно: сохранившиеся результаты тех прогонов лежат на своих
местах (`data/eval_v2/results/`, `data/training/`) и там читаются вместе с кодом,
который их породил. Переносить их сюда без происхождения — значит получить цифры,
которым нельзя верить.

Если всплывёт старый график без привязки — его место здесь, с датой в имени файла.
