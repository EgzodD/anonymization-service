Обезличивание персональных данных — веб-тест

Отдельный тестовый стенд. Проверка текста и документов (.docx/.pdf) на движке модуля.

1. Проверка текста

Кастомный параметр disable_entities — не маскировать эти типы (может только сужать политику; недопустимые названия игнорируются, данные остаются скрытыми):
загрузка политики…
ТипЗначениеScore

2. Проверка документа (.docx / .pdf)

Загрузите файл — стенд вернёт обезличенную версию для скачивания. Готовые примеры — в папке «тестовые_файлы».
