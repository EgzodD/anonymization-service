# Веб-тест обезличивания

Отдельный локальный стенд для ручной проверки модуля — **не часть прод-кода** (`app/`).
Переиспользует ядро (`app.anonymizer` и обработчики документов), но запускается сам по себе.

## Что проверяет
- **Текст** — вставляешь текст → видишь обезличенный с подсветкой типов → «Восстановить» (обратимость).
- **Документы** — загружаешь `.docx` / `.pdf` → скачиваешь обезличенную версию + сводку.
- **Было / стало** — один текст обрабатывают две версии рядом: сервис до плана улучшений
  (коммит `ca69325` от 16.09.2026, прежняя модель ФИО) и текущий. Таблица отличий:
  добавленные и снятые маски, изменённые границы. Готовые примеры — по одному на
  каждое улучшение и один на оставшуюся слабость.

## Запуск
Из корня репозитория, **обязательно python из venv** (в системном нет зависимостей:
transformers, python-multipart и т.д.):
```bash
.venv/bin/python tests/web-тест/server.py
```
Открыть в браузере: **http://localhost:8080**

Для блока «было / стало» стенд сам выкладывает старый код (`git worktree` в
`.cache/web-test-old`, в git не попадает) и поднимает его на `127.0.0.1:8081` —
первый раз 20–40 секунд, состояние видно на странице. Нужна прежняя модель в
`models/person_ruBERT_prev_20260918/`. Другую версию для сравнения можно задать:
`WEBTEST_OLD_REF=<коммит> WEBTEST_OLD_MODEL=<папка модели> .venv/bin/python tests/web-тест/server.py`.

> Если запустить системным `python3` — будут ошибки «No module named 'transformers'»
> и «requires python-multipart». Нужен именно `.venv/bin/python`.

## Готовые тестовые файлы
В папке `тестовые_файлы/`:
- `тестовый_документ.docx` — текст + таблица (метка и значение в разных ячейках);
- `тестовый_документ.pdf`.

Данные в них **синтетические** (вымышленные). Пересоздать:
```bash
python tests/web-тест/сгенерировать_тестовые_файлы.py
```

## Состав
| Файл | Назначение |
|---|---|
| `server.py` | standalone-сервер (FastAPI): страница + /anonymize, /deanonymize, /document, /compare |
| `index.html` | сама страница |
| `сгенерировать_тестовые_файлы.py` | генератор тестовых .docx/.pdf |
| `тестовые_файлы/` | готовые примеры |

Auth здесь нет — это локальный тест. Реальный API (с ключом, гейтом mapping) — в `app/main.py`.
