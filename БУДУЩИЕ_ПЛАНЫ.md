# Будущие планы

Задачи, которые **отложены**, а не отменены. У каждой — почему отложена, что нужно,
чтобы начать, и на каких данных основана. Когда задача берётся в работу, она
переносится в текущий план; когда сделана — удаляется отсюда со ссылкой на коммит.

Обновлено: 18.09.2026.

## Решения владельца, которые действуют сейчас

- **Мат остаётся в тексте как есть** (18.09.2026). Сервис его не маскирует и отдельно
  не обрабатывает; пункт «мат как негативы при обучении» из планов убран.
- **Новые типы ПДн и плейсхолдеры пока не добавляем** (18.09.2026) — см. пункт 1.
- Город без улицы («Проживаю в Москве») адресом не считается и не скрывается —
  тип LOCATION исключён намеренно. Внешний набор hivetrace размечает такой город как
  адрес; если политику решат менять — см. пункт 6.

## 1. Новые типы ПДн (новые плейсхолдеры)

**Что:** распознавание и маскирование типов, которых сервис сейчас не знает:

| Тип | Пример | Сколько на внешних наборах |
|---|---|---|
| КПП | «КПП 770812345» | hivetrace: 94 |
| ОГРН | «ОГРН 5037700123456» | hivetrace: 93 |
| ОГРНИП | «ОГРНИП 304567890123457» | hivetrace: 87 |
| CVC/CVV | «код с обратной стороны карты 472» | hivetrace: 77 |
| Токены и ключи API | «token 5c4b3a2f1e0d…» | hivetrace: 95 |
| Водительское удостоверение | «ВУ 77 12 345678» | dev_rmr: есть в разметке |
| Полис ОМС | 16 цифр | dev_rmr: есть в разметке |
| Военный билет | «АБ 1234567» | dev_rmr: есть в разметке |

**Почему отложено:** решение владельца (18.09.2026).

**Что нужно, чтобы начать:** решить, какие типы добавлять и какими плейсхолдерами
(`<KPP>`, `<OGRN>`… или общий `<ID>`). Учесть: новые плейсхолдеры появятся в ответе
API — интеграции, которые разбирают плейсхолдеры, нужно предупредить заранее.

**Оценка:** 1–2 дня, только правила. Настройка — на dev_rmr (типы там уже размечены).

## 2. Набор из реальных обращений для оценки

**Что:** 200–300 реальных обращений из потока, обезличенных, размеченных вручную
двумя людьми с подсчётом согласия разметчиков.

**Почему важно:** все внешние наборы уже использованы для замеров (статус —
`data/eval_v2/PROTOCOL.md`, поправки 1–5). Без нового слепого набора следующую модель
честно принять нельзя. Кроме того, ни один из наборов не состоит из реальных обращений.

**Что нужно, чтобы начать:** доступ к данным и согласование с юристом (152-ФЗ).

## 3. Переобучение модели ФИО

**Что:** поднять точность ФИО (сейчас 0,77–0,87 против 0,97 у лучших моделей) и
закрыть остаточные пропуски:
- модель захватывает соседнее незнакомое слово или слово с опечаткой;
- слова с опечатками принимаются за имена («роутр», «курьр», «интрнет»);
- фамилии в названиях организаций («ООО Иванов и партнёры»);
- одиночные фамилии в длинных текстах (новости: утечки ФИО 7,9 %);
- строчные иностранные и исторические имена (MultiCoNER: 22 % скрыто не полностью).

**Что нужно, чтобы начать:** набор из пункта 2 — для приёмки.

**Вариант:** дистилляция — модель `redmadrobot-rnd/rubert-base-pii-ner` (MIT,
F1 0,98 на hivetrace, но 36–56 мс) как учитель для нашей быстрой (3,5 мс).
Рецепт — `data/training/DISTILLATION_RECIPE.md`.

**Оценка:** 3–5 дней. Обучение — локально на CPU (`data/training_v3/`).

## 4. Лицензия словаря pymorphy

**Что:** фильтр ложных ФИО (`app/person_filters.py`) использует словарь pymorphy3;
словарь построен на OpenCorpora (CC BY-SA). Сам pymorphy3 — MIT, и он уже был
зависимостью через spaCy.

**Что нужно:** мнение юриста — совместимо ли это с продажей модуля.

## 5. Инфраструктура

- **Приватностный гейт в CI GitHub:** включится, если положить модель в приватное
  хранилище и задать секрет `PERSON_MODEL_URL` (`scripts/fetch_person_model.sh`).
- **Покрытие тестами:** в venv нет `pytest-cov`, `scripts/check.sh` пропускает подсчёт.
- **Реальная сборка Docker** на машине с запасом места: на рабочей машине свободно
  около 9 ГБ, образ с torch занимает 2–3 ГБ.

## 6. Политика по городам (если понадобится)

**Что:** посчитать, какая доля «утечек адресов» на hivetrace — это город без улицы,
который сервис по политике не скрывает; решить, нужно ли скрывать город рядом с ПДн
(например, «Иванов, Самара»).

**Почему отложено:** изменение политики, риск перемаскирования — каждое упоминание
города станет маской.
