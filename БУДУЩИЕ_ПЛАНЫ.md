## 3. Переобучение модели ФИО

**Что:** поднять точность ФИО (сейчас 0,77–0,87 против 0,97 у лучших моделей) и
закрыть остаточные пропуски:
- модель захватывает соседнее незнакомое слово или слово с опечаткой;
- слова с опечатками принимаются за имена («роутр», «курьр», «интрнет»);
- фамилии в названиях организаций («ООО Иванов и партнёры»);
- одиночные фамилии в длинных текстах (новости: утечки ФИО 7,9 %);
- строчные иностранные и исторические имена (MultiCoNER: 22 % скрыто не полностью).

**Что нужно, чтобы начать:** набор из пункта 2 — для приёмки.

**Вариант:** дистилляция — модель `redmadrobot-rnd/rubert-base-pii-ner` (MIT,
F1 0,98 на hivetrace, но 36–56 мс) как учитель для нашей быстрой (3,5 мс).
Рецепт — `data/training/DISTILLATION_RECIPE.md`.

**Оценка:** 3–5 дней. Обучение — локально на CPU (`data/training_v3/`).

## 3а. Синтезатор обучающих данных: языковая модель пишет текст, наш код — ПДн и разметку

**Что:** конвейер автоматической генерации разнообразных обращений с точной разметкой.
Языковая модель пишет только текст с пропусками нашего формата (`{P:datv:full}`,
`{phone}`, `{address}`, `{passport}`…); значения и позиции подставляет наш код
(склонение — функции `build_test_v2.py`, контрольные суммы, «грязные» форматы) —
поэтому разметка точная по построению.

**Шаги:**
1. Матрица сценариев: домен × канал (чат, письмо, звонок, форма) × стиль
   (официальный, разговорный, с опечатками) × набор ПДн × длина.
2. Задание модели + ответ по JSON-схеме (structured outputs), генерация через
   Batch API (скидка 50 %, срочность не нужна).
3. Подстановка значений и расчёт позиций.
4. Автопроверки: ПДн, вписанные моделью ВНЕ пропусков (ловим своим сервисом и
   словарём имён — иначе неразмеченные ПДн и шум в разметке); незакрытые пропуски;
   согласование падежа с предлогом; дубли; сходство с отложенными наборами (Жаккар).
5. Отдельно — трудные негативы: улицы в честь людей, организации, номера заказов.
6. Пилот 50 текстов с ручной проверкой → затем тысячи.

**Модель:** по умолчанию Claude Opus 5 (`claude-opus-5`), альтернатива по цене —
Claude Sonnet 5 (`claude-sonnet-5`); выбор — на пилоте. Цены на 21.09.2026 за 1 млн
токенов (вход/выход): Opus 5 — $5/$25, Sonnet 5 — $2/$10; Batch API — вдвое дешевле.
Грубая оценка на 10 000 обращений: $15–40 (Opus 5, batch), $6–16 (Sonnet 5, batch);
точную цифру даёт пилот с подсчётом токенов.

**Ограничение:** синтетика — для обучения и поиска ошибок, НЕ для приёмки: проверка
на синтетике того же происхождения завышает оценку (вывод статьи, раздел 2).

**Что нужно, чтобы начать:** ключ API Anthropic (`ant auth login` или
`ANTHROPIC_API_KEY`); согласие владельца на расход пилота; подтверждение юриста,
что сгенерированные тексты можно использовать в коммерческом продукте.

**Оценка:** 2–3 дня на конвейер; генерация — фоном.
